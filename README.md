# Scheutplaneet

Twee interactieve rekenverhalen voor het eerste leerjaar, met illustraties, stemmen en begeleide rekenmomenten.

- **Optellen — Herfst in het bos:** Amina, Sami, Maryam en Adam ontdekken de brug over tien.
- **Aftrekken — Wat heb jij vandaag bij?:** Milan en Alina delen onderweg; eerst terug naar tien en daarna de rest eraf.

Open de website bij `index.html` voor het beginscherm. In beide verhalen brengt de knop **Verhalen** je terug naar de keuze. De audio begint na een bewuste afspeelactie.

## Lokaal openen

Start in deze map een webserver:

```sh
python3 -m http.server 8000
```

Open daarna http://localhost:8000/. Gebruik een webserver: rechtstreeks openen als lokaal bestand ondersteunt de JavaScriptmodules niet overal.

## GitHub Pages

De websitebestanden staan in de hoofdmap. Je kunt GitHub Pages instellen op de branch `main`, map `/ (root)`. De relatieve paden ondersteunen ook een repositorypad. De `.nojekyll` voorkomt verwerking door Jekyll. Het uploaden van deze bronbestanden schakelt GitHub Pages niet automatisch in.

Alle gebruikte afbeeldingen, lettertypes en audiobestanden zijn inbegrepen. Er is geen installatie of bouwstap nodig.
